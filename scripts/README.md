# Gradle maintenance scripts

This directory contains helper scripts for maintaining Gradle configuration across the sample projects in this repository.

## `gradle-update.main.kts`

Use this script to update:

- Gradle wrapper version
- Gradle wrapper files
- Gradle daemon JVM criteria

The script reads its configuration from the repository root: `gradle_configuration.properties`

Example:
```.properties
properties gradleVersion=9.3.1 
distributionType=bin

toolchainVendor=AMAZON 
toolchainVersion=21
```

## Requirements

Run the script from the repository root.
```shell
bash kotlin scripts/gradle-update.main.kts
```

The script expects each target Gradle project to already contain:
```text
gradlew 
gradlew.bat 
settings.gradle or settings.gradle.kts 
build.gradle or build.gradle.kts
```

## Update all Gradle projects

To update all discovered Gradle projects with wrapper files:
```bash 
kotlin scripts/gradle-update.main.kts
```

The script walks the repository tree and skips common generated/system directories such as:
```text
.git 
.gradle 
build 
.idea 
.kotlin 
node_modules 
DerivedData
```

## Update one Gradle project
To update only one project, pass the project folder relative to the repository root:
```bash 
kotlin scripts/gradle-update.main.kts practical1/starter
```

## What the script runs

For each selected project, the script runs:
```bash 
./gradlew --no-daemon wrapper --gradle-version --distribution-type 
./gradlew --no-daemon wrapper 
./gradlew --no-daemon updateDaemonJvm --jvm-version --jvm-vendor
```

The `wrapper` task is intentionally run twice.

This follows Gradle’s recommendation for fully updating the wrapper:
```bash 
./gradlew wrapper --gradle-version=&& ./gradlew wrapper
```

## Notes

- The script must be run from the repository root.
- The optional project path must point to a Gradle project folder.
- The project must already have Gradle wrapper files.
- The script does not create wrappers for projects that do not already have them.
- The daemon JVM settings are generated by Gradle’s `updateDaemonJvm` task.
- All Gradle invocations use `--no-daemon`.
